# Design Context

## Users
**Primary Audience**: Potential clients and recruiters looking to hire a frontend developer

**Context**: Evaluating technical skill and design capabilities through portfolio work

**Job to be Done**: Assess whether Okata Miracle can deliver premium, non-basic websites with excellent UX and animations

**Desired Action**: Contact for hire, view project work

## Brand Personality
**Three Words**: Bold, Luxurious, Technical

**Emotional Goals**: 
- Impressed by technical skill (especially GSAP animations)
- Confidence in ability to create premium experiences
- Entertained and engaged through interactive elements

**Voice**: Sophisticated but not stuffy, technically impressive but accessible

## Aesthetic Direction
**Visual Tone**: Dark, sophisticated, technically impressive with smooth animations

**Background**: Dark purple with noise gradient (inspired by p5aholic.me)

**Key Inspirations**:
1. **p5aholic.me** - Simplicity, noise gradient backgrounds, splash screen
2. **adhamdannaway.com** - Creative use of animations, smooth interactions
3. **seanhalpin.xyz** - Component placement, card design, overall design knowledge

**Theme**: Dark mode primary with light mode option

**Typography**: Bold, high-contrast type hierarchy

**Animation Philosophy**: Smooth GSAP animations, scroll-driven reveals, interactive elements that keep users engaged (like the stack button section)

## Design Principles

1. **Premium Over Generic**: Every element should feel intentionally designed, not templated. Avoid AI slop patterns.

2. **Animation as Craft**: Use GSAP to create smooth, impressive scroll animations and interactions that demonstrate technical skill.

3. **Breathing Room**: Generous spacing between sections. Let elements breathe. Proper rhythm through varied spacing.

4. **Interactive Delight**: Keep users engaged through interactive elements (hover states, click interactions, scroll reveals) without being overwhelming.

5. **Technical Sophistication**: Show technical prowess through implementation details—noise gradients, smooth scrolling, card deck animations, horizontal scroll sections.

## Anti-Patterns to Avoid
- Boring, static layouts
- Too flashy/overwhelming (balance is key)
- Generic developer portfolio aesthetics
- Poor spacing and cramped layouts
- Weak typography hierarchy
- Missing or janky animations
